# Code

This directory contains the analysis and simulation code used in the study.

## Structure

- `workload/`: Workload preprocessing and characterization
- `serving_capacity/`: SLO-aware serving-capacity analysis
- `thermal/`: Thermal-management analysis
- `communication/`: Communication and radio-power analysis
- `platform/`: HAPS payload and platform-level feasibility analysis
- `figures/`: Scripts used to generate manuscript figures
