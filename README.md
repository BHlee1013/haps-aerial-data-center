# HAPS Aerial Data Center

This repository contains the code, processed data, simulation models, 
and reproducibility materials associated with the research on 
HAPS-based aerial AI inference infrastructure.

## Project overview

This study investigates the feasibility and capacity of high-altitude 
platform stations (HAPS) for providing text-based large language model 
(LLM) inference services.

The analysis includes:

- Trace-driven LLM workload characterization
- SLO-aware serving capacity analysis
- Communication power analysis
- Thermal management simulation
- HAPS payload-level feasibility analysis
- Sensitivity and robustness analysis
